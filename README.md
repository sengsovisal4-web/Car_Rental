# Car Rental (Flutter)
Setup:
1. `flutter create . --platforms=android,ios`  (generates platform folders, keeps lib/ and pubspec.yaml)
2. `flutter pub get`
3. `flutter run`

Structure: lib/core.dart (tokens, theme, models, state, shared widgets), lib/screens/*.
Flow: Login > Home > Results > Filter > Details > Options > Summary > Payment > Success > Bookings.
